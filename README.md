# CSV Compass

**Узнайте, как изменилась выручка и какие товары повлияли на результат.**

CSV Compass — локальный помощник для анализа выгрузок продаж. Загрузите CSV,
выберите дату, товар и сумму: приложение сравнит два равных периода и ответит
на четыре конкретных вопроса с проверяемыми расчётами. Оно также показывает
пропуски, дубликаты, профили столбцов и распределение значений.

**Local-first sales analysis and CSV explorer.** Compare revenue across equal
periods, inspect product contributions and trace excluded records without uploading data.
The interface is in Russian. No account, API key, or runtime dependency is needed.
Answers follow fixed rules; the application does not use an AI model.

## Возможности

- Четыре вопроса: изменение выручки, снижение по товарам, лидеры и неучтённые строки.
- Сравнение выбранного периода с предыдущим той же длины; таблица расчётов по товарам.
- Точные денежные суммы в целых сотых, проверка переполнения и ошибок данных.
- Автоподбор столбцов по известным заголовкам или ручное сопоставление.
- Явный выбор исключения точных повторов; объяснение некорректных строк.
- Отчёт о продажах с периодами, методикой, всеми товарами и ошибками строк.
- Загрузка файла кнопкой или перетаскиванием.
- Автоматический или ручной выбор разделителя: запятая, точка с запятой, табуляция.
- Показатели по всему файлу: строки, столбцы, пустые ячейки, дубликаты, заполненность.
- Профили столбцов: тип, уникальные значения, пропуски, минимум, максимум и среднее.
- График восьми наиболее частых непустых значений выбранного столбца.
- Поиск по всем строкам и просмотр по 25 записей на странице.
- Отдельный отчёт о качестве CSV с агрегатами, без примеров содержимого ячеек.
- Два встроенных примера: продажи за две недели и таблица с проблемами качества.

## Запуск

Нужен Node.js 24 или новее. Установка пакетов для простого запуска не требуется.

```sh
npm start
```

Откройте **http://127.0.0.1:4173** и нажмите **«Разобрать пример продаж»**.
Если порт занят: `npm start -- 4174`.

Сервер слушает только локальный компьютер и отдаёт только файлы приложения.
Не открывайте `index.html` через `file://`: браузерным модулям нужен HTTP-сервер.

## Быстрая демонстрация

1. Нажмите «Разобрать пример продаж». Все данные вымышлены.
2. За 8–14 сентября 2026 года выручка — **85 000**, за 1–7 сентября — **100 000**.
   Изменение: **−15 000 (−15%)**. В каждом периоде учтено по 6 строк.
3. Выберите «Какие товары просели?»: кофе снизился с **40 000 до 20 000 (−50%)**.
   Чай вырос с 30 000 до 35 000; какао и печенье не изменились.
   Снижение кофе на 20 000 и рост чая на 5 000 объясняют общую разницу −15 000.
4. Выберите «Какие строки не учтены?» и разверните список ошибок: строка 13
   содержит несуществующую дату, строка 14 — пустую сумму. Нумерация без заголовка.
5. Нажмите «Отчёт о продажах ↓»: файл `csv-compass-sales.txt` содержит расчёты
   и методику. Изменение периода скрывает старый ответ до нажатия «Рассчитать».
6. Загрузите собственную выгрузку оплаченных продаж. Для Excel выбирайте **CSV UTF-8**.

Кнопка «Пример качества данных» открывает отдельную таблицу из 18 вымышленных
заказов: 6 столбцов, 3 пропуска, 2 дубликата. Поиск, график и профили доступны
для любого CSV; поиск в таблице не меняет расчёты и отчёты по исходному файлу.

## Как подготовить продажи

Требуются три разных столбца: дата, товар и **полная сумма строки**, а не цена
за единицу. Все строки должны представлять оплаченные продажи в одной валюте:
статус оплаты, количество и валюта автоматически не проверяются.

```csv
date,product,amount
2026-09-07,Кофе,1200.50
2026-09-14,Кофе,1500.25
```

- Даты: `YYYY-MM-DD` или `DD.MM.YYYY`, реальные календарные дни с 1900 года.
- Суммы: неотрицательные, до двух знаков после точки или запятой, без разделителей
  тысяч и обозначения валюты. Десятичную запятую в CSV с разделителем-запятой
  нужно заключить в кавычки. Неверные суммы исключаются, а не округляются.
- Названия товаров группируются с учётом регистра; пробелы по краям убираются.
- Интервал включает обе границы, от 1 до 366 дней. Сравнение — с непосредственно
  предыдущим интервалом той же длины. По умолчанию — 7 дней до последней
  пригодной продажи в файле, включая этот день. Оба периода должны быть с 1900 года.
- По умолчанию повторы учитываются. Исключение удаляет только повторения целой
  строки после первого вхождения, а не совпадения выбранных трёх полей.
- При нулевой предыдущей выручке процент не определён. Дни без записей дают
  ноль; приложение не может проверить, полна ли выгрузка.
- Суммы считаются в целых сотых, максимум `Number.MAX_SAFE_INTEGER` сотых
  на строку и период. Непредставимые суммы строк исключаются; переполнение
  итога останавливает расчёт. Проценты округляются до одного знака.

Это анализ выручки по выгрузке: причины изменений, прогноз, прибыль, возвраты,
отрицательные суммы и число проданных единиц не рассчитываются.

## Как считаются показатели качества CSV

| Показатель          | Правило                                                                                          |
| ------------------- | ------------------------------------------------------------------------------------------------ |
| Пропуск             | Пустая строка или только пробельные символы в ячейке                                             |
| Дубликат            | Все распарсенные ячейки совпадают посимвольно; первое вхождение не считается повтором            |
| Уникальные значения | Различные непустые значения без изменения регистра и пробелов                                    |
| Заполненность       | Доля непустых ячеек; это не оценка достоверности данных                                          |
| Числовой столбец    | Все непустые значения — конечные десятичные числа; допустимы десятичная запятая и научная запись |
| Ведущие нули        | Значения вроде `001` считаются текстом, чтобы сохранить идентификаторы                           |
| Среднее             | Среднее арифметическое непустых числовых значений, включая повторные строки                      |

Парсер поддерживает кавычки, экранирование `""`, разделители и переводы строк
внутри кавычек, UTF-8 BOM и CRLF. Пустые физические строки пропускаются;
явно записанные пустые ячейки сохраняются. Повреждённый CSV отклоняется с ошибкой,
без попытки угадать или исправить значения.

## Ограничения

- UTF-8, не XLSX, не Windows-1251. Первая строка — непустые уникальные заголовки.
- Не более 5 МиБ, 20 000 строк данных и 100 столбцов.
- Автоопределение разделителя использует заголовок. При неоднозначности выберите разделитель вручную.
- В общих профилях CSV даты, валюты, разделители тысяч и смешанные значения
  остаются текстом. Правила анализа продаж описаны отдельно выше.
- Общие числовые профили используют стандартную точность JavaScript и не
  сохраняют произвольную точность. Точные суммы в сотых реализованы в анализе продаж.
- Данные не редактируются, дубликаты автоматически не удаляются.
- Это детерминированный анализатор, без AI-модели или внешних API.

## Конфиденциальность

Приложение читает выбранный файл в память браузера. Оно не отправляет содержимое
файла по сети и не сохраняет его в localStorage, cookies или базе данных.
В нём нет аналитики, внешних шрифтов или CDN. Обновление страницы очищает набор данных.
Внешние подключения дополнительно запрещены Content Security Policy.

Скачанные отчёты остаются на вашем компьютере. В них есть имя файла, заголовки
и агрегаты; **отчёт о продажах также содержит названия товаров** и номера ошибочных
строк. Проверяйте отчёты перед передачей другим людям. Если приложение
размещено на хостинге, хостинг получает обычные запросы страницы и её ресурсов;
содержимое открываемого CSV в эти запросы не включается.

## Разработка и проверки

```sh
npm ci --ignore-scripts
npm run check
```

`check` запускает ESLint, проверку форматирования Prettier и тесты Node.js.
Для форматирования: `npm run format`. Все npm-зависимости нужны только разработке.

Тесты проверяют CSV и граничные случаи, статистику, отчёты, точность сумм,
границы периодов, переполнение, ответы на вопросы, DOM-сценарии загрузки,
поиск, страницы, безопасное отображение текста, конкурирующие чтения файлов и
HTTP-сервер. DOM-тесты используют LinkeDOM и не заменяют визуальную проверку
в настоящем браузере.

```text
index.html          Структура и доступные элементы интерфейса
styles.css          Адаптивное оформление
src/csv.js          Разбор CSV и профилирование
src/app.js          Состояние, загрузка, отображение и события
src/report.js       Текстовый отчёт
src/sales.js        Проверка продаж и сравнение периодов
src/sales-answers.js Ответы по правилам, форматирование и отчёт о продажах
src/sales-view.js   Настройка сравнения и интерфейс вопросов
src/demo.js         Только вымышленные данные
src/main.js         Запуск интерфейса
scripts/serve.js    Локальный HTTP-сервер
tests/             Тесты обработки данных и интеграции
```

Сборка не требуется. Для статического размещения нужны `index.html`, `styles.css`,
`favicon.svg` и папка `src/`. Все пути относительные, поэтому приложение можно
разместить в подпапке сайта. Публикация выполняется отдельно от локального запуска.
