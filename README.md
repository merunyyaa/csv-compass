# CSV Compass

**Разберитесь в CSV-таблице до того, как принимать решения по её данным.**

CSV Compass — небольшое веб-приложение для проверки и исследования таблиц.
Откройте файл: приложение покажет пропуски, точные дубликаты строк, профили
столбцов и распределение значений. Всё обрабатывается в браузере.

**Local-first CSV explorer.** Find missing values, duplicate records, column
statistics, and value frequencies without uploading your dataset to a server.
The interface is in Russian. No account, API key, or runtime dependency is needed.

## Возможности

- Загрузка файла кнопкой или перетаскиванием.
- Автоматический или ручной выбор разделителя: запятая, точка с запятой, табуляция.
- Показатели по всему файлу: строки, столбцы, пустые ячейки, дубликаты, заполненность.
- Профили столбцов: тип, уникальные значения, пропуски, минимум, максимум и среднее.
- График восьми наиболее частых непустых значений выбранного столбца.
- Поиск по всем строкам и просмотр по 25 записей на странице.
- Скачивание текстового отчёта с агрегатами, без примеров содержимого ячеек.
- Встроенный пример из 18 вымышленных заказов: 6 столбцов, 3 пропуска, 2 дубликата.

## Запуск

Нужен Node.js 24 или новее. Установка пакетов для простого запуска не требуется.

```sh
npm start
```

Откройте **http://127.0.0.1:4173** и нажмите **«Открыть пример»**.
Если порт занят: `npm start -- 4174`.

Сервер слушает только локальный компьютер и отдаёт только файлы приложения.
Не открывайте `index.html` через `file://`: браузерным модулям нужен HTTP-сервер.

## Быстрая демонстрация

1. Нажмите «Открыть пример» — появится анализ вымышленных заказов.
2. В графике выберите «Категория», чтобы сравнить частоту категорий.
3. Введите «Астана» в поиск. Показатели наверху останутся по всему файлу.
4. Очистите поиск: пустые ячейки отмечены словом «пусто», повторные строки — «повтор».
5. Нажмите «Скачать отчёт» и откройте `csv-compass-report.txt`.
6. Загрузите собственный CSV. Для экспорта из Excel выбирайте формат **CSV UTF-8**.

## Как считаются показатели

| Показатель          | Правило                                                                                          |
| ------------------- | ------------------------------------------------------------------------------------------------ |
| Пропуск             | Пустая строка или только пробельные символы в ячейке                                             |
| Дубликат            | Все распарсенные ячейки совпадают посимвольно; первое вхождение не считается повтором            |
| Уникальные значения | Различные непустые значения без изменения регистра и пробелов                                    |
| Заполненность       | Доля непустых ячеек; это не оценка достоверности данных                                          |
| Числовой столбец    | Все непустые значения — конечные десятичные числа; допустимы десятичная запятая и научная запись |
| Ведущие нули        | Значения вроде `001` считаются текстом, чтобы сохранить идентификаторы                           |
| Среднее             | Среднее арифметическое непустых числовых значений, включая повторные строки                      |

Парсер поддерживает кавычки, экранирование `""`, разделители и переводы строк
внутри кавычек, UTF-8 BOM и CRLF. Пустые физические строки пропускаются;
явно записанные пустые ячейки сохраняются. Повреждённый CSV отклоняется с ошибкой,
без попытки угадать или исправить значения.

## Ограничения

- UTF-8, не XLSX, не Windows-1251. Первая строка — непустые уникальные заголовки.
- Не более 5 МиБ, 20 000 строк данных и 100 столбцов.
- Автоопределение разделителя использует заголовок. При неоднозначности выберите разделитель вручную.
- Даты, валюты, разделители тысяч и смешанные значения остаются текстом.
- Числа используют стандартную точность JavaScript; приложение не предназначено
  для финансовых расчётов или сохранения произвольной числовой точности.
- Данные не редактируются, дубликаты автоматически не удаляются.
- Это детерминированный анализатор, без AI-модели или внешних API.

## Конфиденциальность

Приложение читает выбранный файл в память браузера. Оно не отправляет содержимое
файла по сети и не сохраняет его в localStorage, cookies или базе данных.
В нём нет аналитики, внешних шрифтов или CDN. Обновление страницы очищает набор данных.
Внешние подключения дополнительно запрещены Content Security Policy.

Скачанный отчёт остаётся на вашем компьютере. В нём есть имя файла, заголовки
и агрегаты, поэтому проверяйте его перед передачей другим людям. Если приложение
размещено на хостинге, хостинг получает обычные запросы страницы и её ресурсов;
содержимое открываемого CSV в эти запросы не включается.

## Разработка и проверки

```sh
npm ci --ignore-scripts
npm run check
```

`check` запускает ESLint, проверку форматирования Prettier и тесты Node.js.
Для форматирования: `npm run format`. Все npm-зависимости нужны только разработке.

Тесты проверяют CSV и граничные случаи, статистику, отчёт, DOM-сценарии загрузки,
поиск, страницы, безопасное отображение текста, конкурирующие чтения файлов и
HTTP-сервер. DOM-тесты используют LinkeDOM и не заменяют визуальную проверку
в настоящем браузере.

```text
index.html          Структура и доступные элементы интерфейса
styles.css          Адаптивное оформление
src/csv.js          Разбор CSV и профилирование
src/app.js          Состояние, загрузка, отображение и события
src/report.js       Текстовый отчёт
src/demo.js         Только вымышленные данные
src/main.js         Запуск интерфейса
scripts/serve.js    Локальный HTTP-сервер
tests/             Тесты обработки данных и интеграции
```

Сборка не требуется. Для статического размещения нужны `index.html`, `styles.css`,
`favicon.svg` и папка `src/`. Все пути относительные, поэтому приложение можно
разместить в подпапке сайта. Публикация выполняется отдельно от локального запуска.
